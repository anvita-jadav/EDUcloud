Institutions still rely on manual or fragmented digital systems for student records, causing redundancy, inconsistency and
administrative overload.

Cloud adoption improves accessibility and scale — but most existing cloud SIS platforms lack strong authentication, RBAC
and encryption.

Sensitive academic data needs confidentiality, integrity and controlled access without sacrificing real-time usability.

PHASE 2 UPDATE

Updated Abstract
EDUCloud is a cloud-based Student Information Management System that centralizes student, faculty and admin
workflows on one secure platform. Building on Phase-I's analysis and design, Phase-II moves into implementation: the

React.js frontend for all three user roles is now functional, while the Java Spring Boot backend, MySQL database, RBAC
enforcement and AES/JWT security layer are under active development on AWS infrastructure. The system targets real-

time attendance, results and notification workflows, with encryption, hashing and secure sessions protecting data at rest
and in transit.

ARCHITECTURE

Cloud-Based System Architecture
Three-tier design
Presentation
React.js frontend on S3 + CloudFront — dashboards, attendance, results, AI chatbot

Application
Java Spring Boot on EC2 — JWT auth, RBAC, REST APIs, validation, email & QR services

Data
Amazon RDS (MySQL) — normalized tables for users, students, faculty, attendance, results

Deployment
AWS: CloudFront (CDN) → S3 (frontend) → EC2 (backend) → RDS (MySQL), with SES for email and OpenAI API for the
chatbot.
